# 商户资金看板 GitHub Pages 上传说明

请把本文件夹里的内容上传到 GitHub 仓库根目录。

上传后仓库首页应该直接看到：

- `index.html`
- `404.html`
- `.nojekyll`
- `assets`
- `README-上传说明.md`

注意：

1. 不要上传压缩包本身。
2. 不要把整个“GitHub上传包-20260724-手机电脑可访问版-v4”文件夹套进去。
3. 需要上传的是这个文件夹里面的内容。
4. `.nojekyll` 是必须保留的隐藏文件，用来避免 GitHub Pages 误处理静态资源。
5. `404.html` 是必须保留的文件，用来保证手机或电脑直接打开子页面时也能正常进入应用。

如果手机访问仍然看到旧页面，请在手机浏览器里刷新缓存，或在访问地址后面加：

`?v=20260724`
